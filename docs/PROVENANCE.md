## NISAR examples

The six README figures and two bundled covariance/intensity subsets are existing
measured NISAR examples from the western Great Lakes, acquired 6 November 2025.
They are not observations from the manuscript's Amazonâ€“Cerrado study area.
The dual example selects HH/HV from a quad GSLC acquisition. The quad example
uses all four measured channels of GCOV with an explicit reciprocity assumption.
See [source URLs and processing](figures/panels/sources.json).
Bundled covariance has already received the looks recorded in each manifest;
the demo re-derives descriptors without applying those looks a second time.
Original NISAR observations remain subject to NASA/ASF data attribution and terms.
No synthetic observations are presented as measured examples.

The polygon AOI reader adapts PyGeoObserver's `aoi.py`, retaining CRS validation
and adding explicit GeoPackage layer selection. Search queries the AOI bounding
box and filters candidate footprints against the polygon union.

## Banner and Python logo

`examples/render_banner.py` builds `docs/banner.svg` from measured GCOV
**HV.tif**, with a 2–98% dB stretch. The complete 128 × 128 subset is displayed
at 3× using nearest-neighbor pixels. No crop, smoothing or sharpening is applied.
The old background enlarged the subset about 9.4× and cropped it to banner shape.
This decorative image is not a geographic map. HV and VH are not interchangeable.

The notebook gallery is regenerated by `pynisar.plot_gallery()` from the bundled
measured covariance, with a fixed −25 to 5 dB power display and the existing
H–α/H–A–α routines. Notebook outputs are computational examples, not paper results.
The neutral reach map uses public-domain Natural Earth boundaries. It contains
no fabricated visitor observations. Local badges are navigation/status labels,
not claims of endorsements, public package releases or measured downloads.
